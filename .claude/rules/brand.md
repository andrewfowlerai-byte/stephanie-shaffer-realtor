# Brand

Russell Real Estate Services navy (`midnight`, `brand`) + a burgundy accent (`flame`, echoing the Russell logo's maroon rule) + warm greige neutrals (`silver`). The Tailwind token NAMES are kept from the template so every component re-skins from `tailwind.config.js` alone and forks share component code. Only hex values change. Fonts: Fraunces (display) + Inter (body).

Stephanie moved from Coldwell Banker Schmidt Realty to Russell Real Estate Services (2026-08). Navy `#182857` and the maroon accent `#97262c` are sampled from the Russell logo (`public/russell-logo.png`), which is in the header.
